自动选图模板库 · 本地预览

本轮预览：http://127.0.0.1:3117/
启动：PowerShell 中设置 $env:PREVIEW_PORT='3117'，然后运行 node intelligence/quant-preview/server.mjs
默认快照：.data/industry-preview/snapshot.json
仅绑定 127.0.0.1。没有修改线上采集、数据库或网站。

结构
templates.mjs：模板名称、适用条件、支持视图、更新规则、未启用原因。
planner.mjs：按数据形状生成图表卡片，输出匹配与校验结果。
metric-normalize.mjs：文章数值严格解析和同披露、同口径分组。
charts.js：受控 ECharts 渲染器，不执行模型生成的代码。
catalog.mjs：行业与原文证据筛选后，调用 planner 生成预览目录。

通用自动匹配
1. 新官方序列：无需预设指标ID，检查单位、合法月份或季度、有限数值；至少两个统计期。
   月度序列可看年月热力图、折线图；每年至少5个月才进入箱线图。
   不混合月度与季度；同统计期取快照中最后一条修订值，缺失不补零。
2. 新文章：文档ID去重后生成行业—来源—文章的旭日图、矩形树图、树图。
   有合法发布日期可进入日历热力图。它们表示资料覆盖，不能解读为产业产出。
3. 新文章指标：同一文档、去除逐字对象前缀后相同的指标名称、单位、数据性质、统计期，至少两个不同对象，
   数值必须逐字出现在已验证证据中，才生成对象对比点图，达到5个对象可展示箱线分布（不推断因果或控制工况差异）。冲突数值、约数和范围不进入。
4. 有原文依据的新关系按六行业更新实体关系图；人工排除记录不恢复。

保留的业务适配器
Transocean 三指标平行坐标、BOEM 登记层级、完整权益构成、规划阶段能力等仍有明确的业务映射。
新指标不会仅因具有两个数字就自动拼入这些业务图。未来新增跨指标组合需要明确主体、口径、共同统计期映射。

Qwen
复用现有 extractArticle / normalizeExtraction 提取实体、关系与文章指标。
本轮新渠道文章在独立临时快照中处理，密钥留在服务器环境中；没有将结果写回线上。
本地网页不调用模型；刷新页面不会重复计费。模型输出不是已验证的单位转换或可比性结论。
当前不自动合并同义指标，也不让模型自主增加模板；不明确的指标保留在源数据清单。

预览刷新
替换本地快照后点击“刷新本地快照”，自动重跑匹配及去重聚合。
预览不自动同步生产，也未部署周期任务。sourceSnapshotAt 表示下载源快照时间，
previewRefresh 表示本轮预览提取完成时间；二者都不是指标统计期。
雷达、漏斗、K线、真实路径保留契约及缺失条件，当前未实现可启用的渲染器。

验证
node --test intelligence/tests/industry-preview.test.mjs intelligence/tests/chart-templates.test.mjs
浏览器遍历所有可切换视图、模板库，检查移动端溢出和运行异常。

扩展方式
新增受控 renderer → templates.mjs 登记适用契约 → planner.mjs 增加数据校验和匹配 →
添加缺字段/重复/冲突/增量测试 → 浏览器验证真实来源数据 → 用户预览后再决定上线。

战略驾驶舱地图预览：同一端口 /dashboard/，使用正式页面资产及本地最新快照，只提供只读API。
全部地图区域支持鼠标及键盘选中，无数据国家保留选中名称与高亮。
连线只有在关联证据中出现明确运输起终点、且无否定或方向冲突时显示箭头；其余为无方向共现脉冲。
使用 requestAnimationFrame 沿 SVG 曲线移动光点；支持减少动态效果偏好，不新增端口或写回线上。
