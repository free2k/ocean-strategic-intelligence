# 海洋能源战略智能智库 · 第一阶段

本模块在原仓库内独立运行，避免更改原站采集、数据库表和服务端口。界面参考既有智库布局，使用真实网页与RSS，所有原始内容保存在受访问密码保护的资料库。

## 模块导航

导航按信息获取、情报分析与研究应用的使用顺序排列：

1. 全球信息感知：来源覆盖、采集任务、更新状态和异常。
2. 情报证据中心：文章、原文、译文、来源链与证据摘录。
3. 产业动态监测：事件与报道线索、人工录入及文件识别。
4. 全球态势总览：已收录情报的地域分布、最新动态与国家关联。
5. 产业关联图谱：主体之间的关系及原文依据。
6. 产业数据洞察：统计序列、项目登记、指标对比与数据明细。
7. 战略研究工作台：证据检索、研究草稿、历史记录及简报导出。

未指定页面时默认进入“全球态势总览”。原有 `#sources`、`#library`、`#events`、`#dashboard`、`#graph`、`#analysis`、`#research` 链接保持有效。

## 数据池导入（2026-10-25）

“数据池 / 图表分析 / 资料分布”页签位于共享筛选区上方。海洋能源与低碳研究共用数据池前端、导入接口和图表模块，本次功能在两套系统同步发布；资料仍汇入当前系统的数据池，使用各自的领域规则。

数据池提供“导入数据或资讯”：先解析、提取和预览，再确认汇入。支持 CSV、TSV、XLSX、JSON 表格，以及 TXT、MD、DOCX、带文字层的 PDF 或粘贴正文。单文件最多 8MB，表格每次最多 1,000 行，PDF 最多 20 页；工作表和字段映射可以调整。扫描件需先转为可复制文字。

导入记录保留批次、原件、文件指纹、工作表及原文依据，列表和卡片区分“采集数据 / 导入数据 / 人工录入”，支持来源类型筛选与 CSV 导出。汇入后刷新图表及共享筛选选项。重复记录跳过；约数、缺失单位和无效统计期会提示检查，同期冲突值保留为指标记录而不覆盖既有趋势。统计序列按对象、指标、单位、性质、领域、国家和频率分别组织，保留零值与负值。

分析使用本地解析、领域规则和逐字数值提取，不触发模型、翻译或采集任务。导入内容只作为资料处理。后续采集快照、低碳本地投影和进程重启会保留导入记录及汇入回执；导入失败不留下部分数据库写入。

验证包含 `insight-import.test.mjs`、`insight-import-postgres.test.mjs`、`request-body.test.mjs` 与既有回归。部署脚本 `deploy/deploy-data-pool-update.py` 校验两套现网程序版本，先执行暂存测试，再同时应用补丁；需要加载保留逻辑的后台进程仅在空闲时重载。回退只恢复程序，不覆盖业务数据。

## 页面响应优化

全球信息感知直接读取 `/api/sensing-page` 的渠道视图，避免在进入页面时加载全文目录、研究筛选和完整工作区。视图保留订阅、RSS、分类数量、同步记录及原有操作；数据时间与后台更新状态在页面可见。浏览器和服务端视图缓存各为 30 秒，过期时先展示上次成功读取的数据，再后台更新；人工修改后强制读取新发布的视图。

情报证据中心通过 `/api/evidence-page` 读取每页 12 篇文章，而不在进入页面时下载约 28MB 的全库目录。服务端索引保留原有去重、领域别名、候选关键词、同名渠道、复核状态及标题／判断依据搜索口径；状态总数和同步进度按完整筛选范围计算。目录原子保存到私有 `evidence-page.json`，每次读取校验系统身份，过期时继续显示带数据时间的已保存结果并后台更新。新目录在后台分批建立索引，完成后切换，期间继续读取上次成功的索引。证据页的地图字典也在后台读取；地图页面会等待字典就绪再绘制。

`/api/evidence-period` 一次返回所选时段统计、历史简报列表和匹配的已保存简报，代替先后读取三次。图表与引用保留该次生成的文档标识、正文版本和发布日期；回放所需的领域样本保留正文，其他已保存原文通过 `/api/evidence-report-document` 按需读取并校验正文版本。生成和发布仍走既有写接口，打开页面不会调用模型。证据读取使用单独的回环线程（海洋 `3107`、低碳 `3207`），避免研究计算或渠道读取阻塞该页；线程只读取固定的私有目录，不连接数据库、不继承模型密钥。部署脚本为 `deploy/deploy-evidence-speed-update.py`。

2026-10-26 情报证据中心线上 Chrome 验收：海洋首次切入 214ms、返回 106ms、浏览器缓存过期 73ms、服务端缓存过期 116ms、全新浏览器直达 443ms；低碳依次为 165ms、66ms、266ms、83ms、898ms。两套实际全库各 22 组筛选与原逻辑对比无差异；用 13,342 篇实际目录刷新时并发读取 24 次，最慢 309ms。543 项回归中 540 通过、3 跳过；浏览器覆盖翻页、状态计数、快速搜索竞态、后台更新保留焦点、当前原文、简报保存的原文版本和失败重试。

渠道视图以 `0600` 权限原子保存到各系统自己的 `INTEL_DATA_DIR/sensing-page.json`，并校验系统、数据库和目录身份。独立工作线程只读取该视图及三个固定 CSS 文件，使研究页的同步计算不再阻塞菜单切换。线程只接收当前系统标识与会话校验配置，不继承模型密钥，不连接数据库。生产 Nginx 用 `deploy/sensing-page-readers.nginx.conf` 将渠道接口和样式分别转发至海洋 `3106`、低碳 `3206` 回环端口；线程随所属前端启停。接口每次校验登录，包含条件缓存读取。

2026-10-26 线上 Chrome 实测（点击菜单至渠道列表出现）：海洋首次 108ms、浏览器缓存过期 68ms、服务端缓存过期 63ms；低碳分别为 131ms、66ms、49ms。全新浏览器直接打开该页分别为 378ms 和 341ms。两套现网分类、订阅与 RSS 对比原接口无差异；回归共 535 项，532 通过、3 跳过。验证包括慢刷新、跨系统缓存隔离、登录校验、写后刷新屏障、研究进程繁忙时读取及输入保留。

标签切换先显示对应页面，按同一筛选范围复用一分钟内的数据读取；刷新在后台完成，过期请求不会覆盖后来选择的页面。采集分类统计单独通过受登录保护的 `/api/source-funnels` 加载，不阻塞主数据接口；服务器合并并发统计读取并缓存一分钟。`/api/data` 支持 gzip，图表依据表格在展开时生成，原始记录保持完整。

程序重启不再写入采集状态文件；实际采集任务仍按原有流程保存状态。升级只替换程序文件，不执行采集、导入或数据库迁移。

国别态势研判支持全球汇总、单国档案和多国联合研判，案例与研判分别展示。领域、来源与北京时间发布日期筛选会核对成果实际引用的全部资料；完整证据不匹配时显示排除原因，并提供清除资料筛选的入口。

每份成果保留资料版本、原发布版本及固定版本原文入口。发布新资料版本后，旧成果仍可在“历史已发布成果”中查阅；历史成果单独标明版本，本期角色、关系与事件统计只使用当前版本记录。历史版本链接可刷新恢复，也可返回最新版本。

验证：`node --test intelligence/performance.test.mjs`，以及浏览器中的连续切换、慢请求、研究输入保留和绘图依据展开检查。

## 运行

Node.js 20.6+。复用项目已有的 pg、undici、linkedom、Readability、fast-xml-parser、openai 依赖。

```powershell
node --env-file=.env intelligence/collect.mjs
node intelligence/refine-snapshot.mjs
node --env-file=.env intelligence/import-series.mjs
node --env-file=.env intelligence/server.mjs
npm run test:intelligence
```

本地读取 `.data/intelligence/snapshot.json`。生产通过 `run.mjs` 使用已有 PostgreSQL 连接，但只创建/写入独立 `ocean_intel` schema。密码使用既有 `SITE_PASSWORD`。没有密码时默认不放行；仅本地开发可设置 `INTEL_ALLOW_NO_AUTH=true`。

## 配置

- `INTEL_DATA_DIR`：私有原件、快照与研究记录目录。
- `INTEL_DATABASE_URL`：可选；配置则数据库必须连接成功，不能静默降级。
- `INTEL_PORT`：默认3101，只监听127.0.0.1。
- `INTEL_SENSING_PORT`：渠道读取线程端口，海洋默认3106、低碳默认3206，只监听127.0.0.1。本地同时运行多个实例时分别指定端口。
- `INTEL_EVIDENCE_PORT`：证据读取线程端口，海洋默认3107、低碳默认3207，只监听127.0.0.1。本地同时运行多个实例时分别指定端口。
- `INTEL_BASE_PATH`：生产路径 `/ocean-intelligence/`，用于会话Cookie。
- `INTEL_SINCE` / `INTEL_UNTIL`：采集日期边界；第一批2026-01-01至采集当日。不是全量覆盖。
- `INTEL_MAX_PER_SOURCE`：每源本轮目标数量，默认12。
- `INTEL_ENABLE_AI`：默认关闭；只有明确配置为true，才会调用付费模型及embedding。
- 模型启用后复用 `OPENAI_BASE_URL`、`OPENAI_API_KEY`、`CHAT_MODEL`、`EMBEDDING_MODEL`。向量模型必须支持所配置的1024维，旧向量须重建。
