# 页面加载性能优化与腾讯云部署

日期：2026-10-25。适用范围：电脑端知识库、海洋能源及低碳研究的共享读取链路。

## 修改范围

本次优化读取、缓存和传输，沿用现有分类、筛选、统计口径、研究计算、模型策略及 Batch 调度。腾讯云服务器规格没有变更。按本轮后续授权，已解除低碳单核 20% CPU、640 MiB 内存、进程数及人为 V8 堆上限，恢复 Node 自动管理内存；只读页面接口允许并发，写入仍按原逻辑串行。

1. **相同筛选条件复用计算。** 图表页和研究工作台原先因为参数顺序、空值不同而重复生成整套目录。现在统一缓存键，领域、国家、来源、日期等有效条件仍分别隔离。
2. **已发布资料先核对版本。** 工作区未变化时只查询版本，不传输和解析整个 JSON；有更新时仍按同一数据库快照、分块校验和原人工修订逻辑读取。
3. **减少重复遍历。** 证据归属通过文章 ID 索引查询，国家选项通过集合汇总；IEA 数量统计直接计数，保留原项目去重、来源、领域、国家和日期规则。
4. **复用关键词正则。** 复用有上限的正则缓存，保持原词边界及 Unicode 匹配语义，不改变分类规则和编译版本。
5. **来源统计共享请求。** 工具栏和来源页面合并相同的读取；写入、重新读取和登录变化仍正确失效，旧在途响应不会覆盖更新结果。
6. **分类列表精简。** 列表请求使用 `view=inventory`，保留全部文章、筛选字段、当前判断及分类差异。省去重复存储副本、处理检查点等列表不用的字段；默认旧接口和完整原文详情继续可用。
7. **分类台账按源版本复用。** 在原 15 秒检查节奏下，用只读的行版本指纹识别源表新增、更新和删除；无变化时复用已有台账，最长五分钟重新完整读取。未来发布日期跨过当前时间时也会失效。版本检查失败则执行原完整读取。
8. **大响应条件读取。** 分类列表和图表目录使用私有 ETag 校验；版本相同返回 304，复用当前浏览器已取得的内容。不同筛选、源版本和规则不会共用结果，显式刷新仍可强制读取。图表缓存保存 JSON 文本，每次提供独立对象，避免图表选项互相修改；缓存总量限制为 64 MiB、最多两份。

## 功能与费用

- 文章、当前分类理由、模型复核记录、原文引用、筛选计数和图表计算口径保留。
- 人工修改及显式刷新会取得更新结果；读缓存不会创建采集、分类、翻译、识图、研究生成或付费补调任务。
- 低碳仍采用共享采集、只读源适配、本地规则与已有结果复用；不持有模型 Key。
- 原模型 Key、降本配置、处理配置及 Batch 定时器保持原配置；原系统正常业务仍按既有策略运行。
- 缓存失效或第一次请求新资料时，需要实际读取及计算；首次大型图表仍需要实际计算和传输。版本不变时的往返切换是本次主要改善场景。

## 线上实测

1440 × 1000 电脑浏览器、真实腾讯云数据。以下是不同验证轮次的现场采样，受网络、并行采集及首次计算影响，不作为所有请求的固定时延承诺。

| 海洋页面 | 同一会话首次进入 | 往返切换 |
| --- | ---: | ---: |
| 来源信息感知 | 13.25 秒 | 1.39 秒 |
| 情报证据中心 | 3.81 秒 | 0.10 秒 |
| 行业数据洞察 | 17.64 秒 | 0.30 秒 |
| 研究工作台 | 8.39 秒 | 0.20 秒 |

证据页测试专门让浏览器缓存过期，再核对服务端版本：台账未变化时响应为 304，正文传输为零。图表再次进入也验证为 304，省去约 2.9 MB 压缩响应的重复下载。

按后续授权移除低碳资源上限后，完成全部电脑菜单验证：

| 低碳页面 | 原 20% CPU 配置下首次进入 | 解除限额后首次进入 | 解除限额后往返 |
| --- | ---: | ---: | ---: |
| 来源信息感知 | 18.47 秒 | 2.36 秒 | 0.06 秒 |
| 情报证据中心 | 12.27 秒 | 3.48 秒 | 0.10 秒 |
| 行业数据洞察 | 36.85 秒 | 3.93 秒 | 0.11 秒 |
| 研究工作台 | 22.61 秒 | 1.63 秒 | 0.19 秒 |

低碳全球态势首次约 2.74 秒、行业监测列表约 0.61 秒；同轮浏览器无脚本错误。资源核验显示 `CPUQuotaPerSecUSec=infinity`、`MemoryMax=infinity`、`TasksMax=infinity`，两个低碳服务命令均没有人为 V8 堆大小参数。原只读源账号、查询超时及数据库隔离继续生效。

优化前采样中，图表首次进入约 20.85 秒、研究工作台约 29.02 秒；图表和研究存在相同条件重复计算。公共接口的一次上线后采样中，国家选项约 73 毫秒、概况数据约 378 毫秒，筛选项、来源、领域及范围计数与发布前保存的响应一致。

- 切换控制器的 5 项 Python 测试通过；Nuxt 生产构建通过。
- 比较数据库源版本变化、未来发布日期到期及版本查询失败，确认更新能够使缓存失效。
- 线上比较原筛选项、来源、领域和范围统计；测试详情接口继续返回完整原文及判断依据。
- 浏览器验证包括来源、证据、图表、研究及版本未变时的重复切换。原登录鉴权先于条件读取，退出后不能凭 ETag 获取资料。
- 本次实际重载网页进程，原采集、处理、共享只读代理、Batch 和每日简报独立工作进程未因程序发布重启。

验证记录放在同目录 `page-speed-audit-2026-10-25/`；大体积资料响应和临时登录凭据不进入 Git。
